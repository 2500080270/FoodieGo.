# 🍔 Foodie Go – Online Food Delivery System

Foodie Go is a food delivery web application inspired by Swiggy and Zomato. It allows users to explore restaurants, order food, and track deliveries through interactive maps.

## ✨ Features

**User Module**
- Login and Signup
- Browse restaurants and food menus
- Add items to cart and checkout
- Order tracking with interactive maps

**Admin Module**
- Professional admin dashboard
- Add and manage restaurants
- Add, edit, and delete food items
- Manage customer orders

## 🛠️ Technologies Used
- React.js
- Vite
- HTML, CSS, JavaScript
- Local Storage
- OpenStreetMap

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Open the localhost URL displayed in your terminal.

## 📌 Project Purpose

Developed as a college project to gain practical experience in React development, frontend design, and building user and admin modules.
